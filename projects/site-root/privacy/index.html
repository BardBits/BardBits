Privacy Policy

Last updated 18 August 2026

BardBits does not ask who you are. There are no accounts, no sign-ups, no advertising networks, and no analytics. This site sets no cookies. The short version: the tools run in your browser, and nothing you type or generate is sent to us.

This policy covers bardbits.ca and every project on it. Browser storage belongs to the whole domain rather than to any one page, and the site is run by one person, so a single policy applies throughout. Where a particular project does something different, it is described in its own section below.

What is not collected

  • No accounts, names, email addresses, or payment details.
  • No cookies are set by this site.
  • No analytics, tracking pixels, session recording, or fingerprinting.
  • No advertising networks, and no data sold or rented to anyone.
  • No third-party scripts of any kind. The site enforces this technically as well as by policy: a Content-Security-Policy header blocks the browser from loading scripts, images, or frames from other domains.

Storage in your browser

Some projects remember things using your browser's own storage. Whatever is stored stays on your device, is readable only by bardbits.ca, and is never transmitted to any server — there is no server to transmit it to, because the site is static files and the pages are blocked from contacting any other domain.

How long it lasts differs by project, so each one says below. Clearing site data in your browser removes all of it immediately, whichever kind it is.

Name generators

The cottage, cabin, and beach house name generators keep the list of names you have already drawn, so it survives moving between them. It uses sessionStorage under keys beginning retreat-names:history:, holds only generated names, and is erased when you close the tab.

Boat names

The boat name generator keeps the names you have already drawn, one list per style, so moving between the funny, nautical, sailboat, pontoon and fishing pages does not lose them. It uses sessionStorage under keys beginning boat-names:history:, holds only generated names — at most twenty per style — and is erased when you close the tab.

Reversi

The Reversi game uses localStorage, which unlike the above persists after you close the tab and stays until you remove it. That is deliberate: a saved game that vanished when you closed the tab would not be worth offering. It keeps three things, all under keys beginning reversi::

  • The game in progress — the position on the board, whose turn it is, the moves so far, and which colour you are playing, so a refresh or a stray back button does not destroy a long game.
  • Your settings — difficulty, preferred colour, and whether legal moves and animations are shown.
  • Your record — how many games you have won, lost and drawn at each difficulty.

None of it identifies you, and none of it leaves your device. The game page has a control that removes all three at once — the saved game, your settings and your record — so you do not have to go through your browser's settings to remove them.

Server logs

The site is served through Amazon CloudFront, which records a line for each request. These logs are used to see which pages are being requested, what is failing, and what is slow. They are kept for 30 days and then deleted automatically.

Each entry records:

  • Date, time, and the edge location that served the request
  • The page requested, the HTTP method, and the response status and size
  • How long the request took
  • Your browser's user-agent string and the page that referred you, if any
  • The country the request came from

Visitor IP addresses are deliberately not recorded. The logging configuration omits the IP address field and the cookie field, so the logs cannot be tied back to an individual visitor. This was a choice rather than an oversight: the questions these logs answer do not require knowing who anyone is.

Third parties

Hosting

The site is hosted on Amazon Web Services (S3, CloudFront, and Route 53). AWS processes requests in order to deliver the site and stores the logs described above on our behalf. It does not use that data for its own purposes.

Affiliate links

This site intends to use affiliate links — links to products on other websites where, if you follow one and buy something, this site may earn a commission at no additional cost to you. None are in place yet. Wherever they do appear, they will be disclosed on the page itself.

Such links would be administered by an affiliate network, most likely Rakuten Advertising, for merchants including Etsy. Following one would take you to a site run by someone else, and from that point their privacy policy applies, not this one. Networks and merchants commonly set cookies on their own domains to attribute a purchase to the referring site. Nothing identifying you would be passed to them by BardBits; the link itself carries only a code identifying this site as the referrer.

Your choices and rights

Because no accounts exist and no personal data is collected, there is very little held about you to begin with. Nothing in the server logs identifies an individual, so a request to access or delete "your data" generally cannot be matched to a person, and the logs expire on their own within 30 days.

Browser storage is entirely under your control. Clearing site data in your browser removes all of it. Closing the tab removes some of it — see the section above, which says per project which kind is used, and note that Reversi's saved game and record survive until you clear them or use the control on the game page. Depending on where you live you may have rights under laws such as PIPEDA in Canada, the GDPR in the UK and EU, or the CCPA in California. If you would like to exercise one, or want to know what is held, get in touch using the address below.

Children

These tools are suitable for all ages, but they are not directed at children, and no information is knowingly collected from anyone.

Changes

If the way this site handles data changes — for example if a project begins using something not described here — this page is updated and the date at the top changes with it.

Contact
